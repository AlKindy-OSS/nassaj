# الجسد والمحرّك: من ينفّذ ومن يجيب

أكثر ما يُربك في نسّاج أن كلمة **«مزوّد»** تُستعمل لشيئين مختلفين تماماً. هذه الصفحة تفكّ الالتباس مرة واحدة.

---

## الفكرة في سطر

كل تشغيل في نسّاج هو ثلاثة أشياء لا شيء واحد:

```
{ الجسد ، المحرّك ، النموذج }
```

**الجسد** يقرأ ملفاتك وينفّذ الأوامر. **المحرّك** يكتب الكلمات. **النموذج** هو أي عقل داخل ذلك المحرّك.

تشبيه: الجسد **سائق** يعرف الطريق ويملك مفاتيح البيت. المحرّك **مُحرّك السيارة**. تبديل المحرّك لا يغيّر السائق ولا يغيّر وجهته — يغيّر من يولّد الحركة فقط.

---

## المصطلحات: عربي ↔ إنجليزي

| المصطلح | English | ما هو بالضبط |
|---|---|---|
| **الجسد** أو **الهارنس** | body / harness | البرنامج الذي يملك الأدوات والأذونات والجلسات: `claude`, `codex`, `opencode`, `kimi`. هو من يقرأ ملفاتك ويشغّل الأوامر |
| **المحرّك** | engine | **عنوان HTTP فقط**، يولّد التوكنز ولا شيء غيره: `api.moonshot.ai`, `api.z.ai` |
| **النموذج** | model | معرّف يُطلب من المحرّك: `kimi-k3`, `glm-5.2`, `claude-opus-5` |
| **المزوّد** | provider | ⚠️ كلمة ملتبسة — تُستعمل للجسد وللمحرّك معاً. **هذا مصدر معظم الحيرة** |
| **الكتالوج** | catalog | قائمة النماذج التي يعيدها المحرّك حين نسأله |
| **الاعتماد** | credential | ما يثبت هويتك عند المورّد: مفتاح أو توكن |
| **مفتاح API** | API key | نصّ ثابت تُصدره من موقع المورّد، وتدفع مقابل استهلاكه |
| **OAuth** | OAuth | تفويض بتسجيل دخول في المتصفّح، ينتج توكناً مؤقتاً مرتبطاً بحسابك |
| **الاشتراك** | subscription | خطة شهرية (مثل Claude Max)، اعتمادها OAuth لا مفتاح |
| **الخانة** | slot / target | أين يُخزَّن الاعتماد، ومن يقرؤه فعلاً |

## لماذا لا يكفي أن نقول «GLM»؟

لأن «GLM» وحدها لا تعني شيئاً قابلاً للتنفيذ. الحقيقة تعيش في **الزوج** (جسد × محرّك):

| الزوج | الحال |
|---|---|
| Claude × GLM | يعمل — بمفتاح Z.AI مخزَّن عندنا |
| OpenCode × GLM | يعمل — لكن بخانة اعتماد **أخرى تماماً** داخل OpenCode |
| Codex × GLM | مغلق عند المورّد — لا يوجد المسار أصلاً |

ثلاث إجابات مختلفة لنفس الكلمة. ولهذا تُعرض المحرّكات **داخل صفحة كل وكيل**، لا كقائمة مستقلة: القائمة المستقلة تعرض «GLM» صفّاً واحداً فتكذب على حالتين من الثلاث.

### والمورّد كيان ثالث

انتبه إلى صفّ رابع في الجدول أعلاه لا يظهر في اسم المحرّك: **المورّد** (vendor) — الشركة التي تُصدر الاعتماد وتُبطله وترسل الفاتورة. ‏`kimi` تعني ثلاثة أشياء دفعة واحدة: **Moonshot** (المورّد)، و**Kimi CLI** (الجسد)، و**api.moonshot.ai** (المحرّك).

والاعتماد ملك **المورّد** وحده. ولهذا مفتاح Moonshot الواحد يقرؤه جسد Kimi ومحرّك Kimi تحت Claude معاً — سجلّ واحد بقارئين، لا نسختان.

## كيف يُدخَل إلى المحرّك؟ بمفتاح API حصراً

**لا OAuth للمحرّكات — أبداً.** وليس هذا نقصاً في نسّاج، بل ثلاثة أسباب متراكبة:

**1 — تقنياً.** تشغيل جسد على محرّك آخر يتمّ بحقن متغيّرين في بيئة عملية الجسد قبل انطلاقها:

```
ANTHROPIC_BASE_URL   = https://api.moonshot.ai/anthropic
ANTHROPIC_AUTH_TOKEN = <مفتاحك>
```

الجسد لا يعرف أنه تبدّل — يظنّ أنه يكلّم أنثروبيك. والخانة التي يقرأ منها التوكن لا تقبل إلا **نصّاً واحداً**. لا مكان فيها لدورة OAuth.

**2 — عند المورّدين.** Moonshot وZ.AI لا يعرضان OAuth لواجهاتهما البرمجية أصلاً؛ يصدران مفاتيح فقط.

**3 — قانونياً، وهو الأهمّ.** توكن OAuth الذي تملكه هو توكن **اشتراك أنثروبيك**. إرساله إلى Moonshot ليس عديم الفائدة فحسب، بل تسريب اعتماد لطرف ثالث. وحارس القاعدة الحديدية في نسّاج يمنع هذا المسار بنيوياً.

### الخلاصة

| الطريق | الاعتماد |
|---|---|
| **الجسد** إلى مورّده الأصلي | OAuth / اشتراك (كلود باشتراكك، كوديكس باشتراك OpenAI) |
| **المحرّك** | مفتاح API لا غير |

المحوران لا يتبادلان اعتماداتهما.

> [!IMPORTANT]
> **الفوترة تتبع الاعتماد لا الواجهة.** محادثة على جسد كلود ومحرّك كيمي تُخصم من رصيد **Moonshot**، لا من اشتراك كلود — مهما بدت الواجهة «كلود».

## أين تجد هذا في الواجهة؟

- **الإعدادات ← المورّدون والاعتمادات:** صفّ لكل مورّد، وهو **المكان الوحيد** الذي يُدخَل فيه أي مفتاح. تحت كل مورّد سطر «يُستهلك في» يعدّد كل موضع يقرؤه.
- **الإعدادات ← الوكلاء ← \<الوكيل\> ← المحرّكات:** جدول محرّكات ذلك الوكيل وحده — **قراءة فقط**، وشارة واحدة لكل صفّ تجمع القدرة المعلنة وحالة الاعتماد معاً. لا خانة إدخال ولا سطر حالة ثانٍ، عمداً: مؤشّران لحقيقة واحدة يفترقان حتماً.
- **الإعدادات ← الوكلاء ← \<الوكيل\> ← الحساب:** تسجيل دخول ذلك الوكيل وجلسته. لا مفاتيح هنا — أُزيلت وصار مكانها إشارة إلى صفحة المورّدين.
- **منتقي النماذج داخل المحادثة:** هناك يُختار المحرّك لتشغيل بعينه — صفّ مثل «Claude engine on Kimi».
- **محادثة قائمة لا يُبدَّل محرّكها.** المحرّك يُثبَّت عند الإنشاء؛ للتبديل ابدأ محادثة جديدة.

> [!NOTE]
> **«يوجد مفتاح» يظهر في أكثر من مكان؟** هذا صحيح لا خطأ: المفتاح سجلّ واحد لكل (مستخدم، مورّد)، ويُقرأ حيثما يلزم. تدخله **مرة واحدة** في صفحة المورّدين، وبقيّة الشاشات تعرض حالته فقط.

## علامات تُقرأ في جدول المحرّكات

| الوسم | معناه |
|---|---|
| **مقيس** (measured) | جرى تشغيل فعلي على هذا الجهاز وشوهدت نتيجته |
| **مستنتَج** (inferred) | من وثائق المورّد؛ لم يُشغَّل عندنا بعد |
| **يعمل اليوم** | المسار كامل ومقيس |
| **جاهز — لم يُقَس هنا** | الاعتماد مخزَّن فلا حاجز، لكن نسّاج لم يشغّله بعد |
| **يحتاج اعتماد \<المورّد\>** | الهندسة تمّت، والناقص هو المفتاح |
| **لم يصل بعد** | الحاجز كودنا نحن، لا المورّد |
| **غير متاح عند المورّد** | النقطة غير موجودة عنده — ليس تأجيلاً بل إغلاقاً |

القاعدة التي يلتزمها نسّاج: **لا يُعرض وسم أخضر لمسار لم يُرجع توكناً قط.**
